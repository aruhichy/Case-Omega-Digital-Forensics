The following procedure was followed for preparing the academic evidence dataset:

4. Prepared a CSV file containing fictional affected-file records.
5. Prepared synthetic server event records.
6. Saved all files in the dedicated evidence folder.
7. Planned SHA-256 hashing to verify the integrity of the prepared files.

The hashes can later be recalculated and compared to check whether the files have changed since the recorded baseline.
