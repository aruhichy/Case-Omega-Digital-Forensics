## 2. Background of the Incident

OmegaCare Multispeciality Hospital is a fictional
healthcare organization that uses computer systems
to maintain administrative records, appointment
information, billing records and hospital operations.

On 20 November 2026, hospital employees reported
that several files stored on the hospital network
were inaccessible.

The IT department noticed unusual file modifications
and a suspicious ransom message on the affected
system.

The hospital suspected a ransomware incident and
initiated a digital forensic investigation.

## 4. Initial Observations

The following observations are included in the
fictional incident scenario:

1. Hospital files became inaccessible.
2. Unusual file modifications were reported.
3. A suspicious ransom message appeared.
4. An unusual login was recorded.
5. A suspicious outbound network connection
   was identified in the simulated logs.

These observations are scenario assumptions and
will be examined using simulated evidence.

## 5. Investigation Objectives

The investigation aims to:

- Identify potentially affected systems.
- Document and preserve digital evidence.
- Demonstrate forensic image acquisition.
- Verify evidence integrity using SHA-256.
- Maintain a chain of custody.
- Analyze simulated ransomware behavior.
- Reconstruct the incident timeline.
- Prepare a legal and technical investigation report.

## 6. Scope and Limitations

This investigation is strictly an academic simulation.

All hospital details, incident records, timestamps,
and initial observations are fictional.

No real hospital infrastructure or patient data
is involved.

The investigation cannot establish the identity
of a real attacker or prove a real cybercrime.
